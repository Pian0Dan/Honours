# Abstract

Sortition, the random selection of individuals to form panels, has seen a renaissance in recent years, as more and more institutions realise the value of direct community and stakeholder input in deliberation and policymaking. These panels have proven to be massively beneficial in terms of improving the quality of outcomes reached, increasing public trust and engagement, and creating more inclusive and representative processes. However, there are still many challenges to overcome in order to ensure that these panels are truly representative and selected effectively. This thesis aims to evaluate current sortition methods and community representation processes, as well as to investigate how sampling biases and algorithmic design can impact panel representativeness. By investigating these factors, we can develop a greater understanding of existing tools and procedures, how they work, how they fall short, and what it would mean for them to be more representative. This enabled the creation of a diagnostic tool ("Intersection Inspector"), for use by practitioners to make the process more transparent, and to assess and improve the representativeness of selected sortition panels.
